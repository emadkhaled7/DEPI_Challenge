# DEPI 25 Days Flutter Challenge

This repository contains my work for the DEPI 25 Days Flutter Challenge, a daily Flutter practice challenge focused on building and improving my UI development skills.

The idea of the challenge is simple: build one Flutter screen every day for 25 days. Each day focuses on creating a different interface while practicing Flutter widgets, layouts, spacing, styling, navigation, and responsive design.

Throughout the challenge, I am exploring different types of applications and user interfaces, including food and restaurant screens, coffee applications, educational platforms, e-commerce interfaces, and other everyday app concepts.

The main goal of this challenge is to become more comfortable with Flutter by practicing consistently and turning different design ideas into functional user interfaces. It also gives me the opportunity to improve my attention to detail and learn how to structure Flutter projects in a clean and organized way.

I am documenting all the screens and progress in this repository so that the development process can be followed from the first day to the final day of the challenge.

The project is built using Flutter and Dart, with a focus on using Flutter's built-in widgets and Material Design components to create clean and user-friendly interfaces.

This challenge is part of the Digital Egypt Pioneers Initiative (DEPI) training program.

By the end of the challenge, the repository will contain 25 different Flutter screens, representing 25 days of continuous practice and development.
